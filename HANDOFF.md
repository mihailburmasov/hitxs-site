# HANDOFF — HitXS (изделия из дерева ручной работы)

Статус на 2026-08-12: сайт собран, задеплоен на GitHub Pages, рабочий.
Это редизайн существующего сайта hitxs.ru — мастерской в Казани,
делающей разделочные доски, подносы, посуду и мебель из дерева.
Ниже — всё, что нужно знать, чтобы продолжить работу или передать
проект дальше.

## Ссылки

- **Репозиторий:** https://github.com/mihailburmasov/hitxs-site
- **Живой сайт:** https://mihailburmasov.github.io/hitxs-site/
- **Деплой:** GitHub Pages, ветка `main`, папка `/ (root)`, легаси-сборка.
  Собирается автоматически при пуше в `main`.
- **Оригинал (для сверки контента/цен):** https://hitxs.ru — на него же
  сейчас указывает `<link rel="canonical">` на всех страницах, хотя
  реально сайт крутится на `github.io`. Если этот редизайн должен
  заменить хостинг на `hitxs.ru`, canonical и `og:url` — верные; если
  нет, их нужно поменять на адрес github.io.

## Стек

Статика без сборки: HTML-страницы + `assets/css/style.css` +
`assets/js/*.js`. Открывается напрямую в браузере, npm/зависимостей нет.
Шрифты — Google Fonts (Fraunces для заголовков + Manrope для текста)
через `@import` в `style.css`.

## Дизайн-система

- Палитра: тёплый айвори фон (`--bg: #FAF6EF`), графитово-коричневый
  текст (`--text: #2A2019`), терракотовый акцент (`--accent: #B24A26`,
  «обожжённая глина»), тёмное дерево для футера (`--brand-dark`).
- Шрифты: Fraunces (заголовки, вариативный serif) + Manrope (текст).
- Токены — в начале `assets/css/style.css` (`:root`).

## Как продолжать работу

1. Если нужна рабочая форма заказа — завести аккаунт на Formspree,
   получить ID формы, вставить в `FORM_ENDPOINT`.
2. Уточнить у клиента судьбу домена (пункт про canonical выше).
3. Уточнить, нужна ли ссылка на MAX-мессенджер вместо звонка.
4. Каталог (`products.js`) сгенерирован автоматически — если товары
   на оригинале hitxs.ru изменятся (цены, наличие), потребуется
   пересобрать этот файл заново, а не редактировать вручную построчно.
